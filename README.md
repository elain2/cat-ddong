# 🐾 고양이 사랑방

> 귀엽지만 쓸 데 없고, 내가 즐거운 것을 만들자.
> 마치 귀여운 똥을 싸는 고양이처럼.  — *project cat-ddong*

설문에 답하면 **내 행동 패턴을 닮은 픽셀 고양이**가 찾아오는 브라우저 서비스예요.
찾아온 고양이는 고양이들이 모이는 **사랑방**에서 다른 손님 고양이들과 어울리고, 만난 고양이는 **도감**에 모여요.

## 어떻게 즐기나요

1. **입장**: 집사 고양이가 인사하며 설문을 시작해요.
2. **설문 8문항**: "쉬는 날 아침 눈을 떴다. 지금 기분은?" 같은 가벼운 객관식이에요.
3. **고양이 등장**: 답변이 고양이의 성격과 외형이 되어 3프레임 애니메이션으로 나타나요.
4. **이유 풀이**: "귀가 쫑긋해요 → 새로운 얼굴이 반가워요."처럼 왜 이렇게 생겼는지 알려줘요.
5. **사랑방 입장**: 방 안을 오가는 손님 고양이를 눌러 만나고 도감을 채워요.

같은 설문이라도 성격 축과 취향 조합에 따라 전혀 다른 고양이가 나와요.

### 내 답변이 곧 외형이에요

설문은 행동 패턴으로 **성격 4축**을 재고, 외형은 각 축이 직관적으로 드러나는 곳에 은유로 나타나요.

| 성격 축 | 외형에 나타나는 곳 | 은유 |
|---|---|---|
| 에너지 (느긋 / 보통 / 활발) | 체형, 꼬리, 눈 | 느긋: 통통하고 꼬리가 짧고 눈을 감고 있어요. 활발: 날씬하고 꼬리가 꼿꼿해요. |
| 사교성 (독립 / 보통 / 친화) | 귀, 입, 볼 | 독립: 귀가 눕고 입이 일자예요. 친화: 귀가 쫑긋하고 W 입에 볼이 발그레해요. |
| 섬세함 (털털 / 보통 / 예민) | 털 무늬 | 털털: 얼룩과 삐죽 털이 있어요. 예민: 깔끔한 단색이에요. |
| 대담함 (신중 / 보통 / 대범) | 눈 크기 | 신중: 작은 눈. 대범: 크고 반짝이는 눈. |
| 좋아하는 시간 | 털색 | 아침=크림, 해질녘=오렌지, 밤=검정, 새벽=은회색 |
| 퇴근 후 저녁 | 액세서리 | 회식=넥타이, 카페=안경, 혼술=소주병, 바로 집=맨몸 |

## 사랑방

<p align="center">
  <img src="docs/room.png" alt="사랑방" width="480">
</p>

- 네코아츠메처럼 방 전체를 한 화면에서 내려다봐요.
- **시즌**에 맞게 꾸며져요. 봄 / 여름 / 가을 / 겨울 버튼으로 바꿔볼 수 있고, 기본값은 오늘 날짜예요.
- **손님**은 도감 60마리 중 4마리가 30분마다 바뀌어요. 머리 위에 `!`가 떠 있으면 아직 못 만난 고양이예요.
- 내 고양이와 도감은 브라우저(localStorage)에 저장돼요.

## 만드는 방식

- 이미지 파일이 하나도 없어요. **코드가 픽셀을 직접 찍어서** 32x32 고양이를 만들어요.
- 고양이 속성은 시드로 복원되기 때문에 서버나 DB가 필요 없어요. (정적 사이트)
- 같은 답변과 별명이면 항상 같은 고양이가 나와요.

## 로컬에서 실행

빌드가 필요 없어요. 정적 서버만 띄우면 돼요.

```bash
python3 -m http.server 8765
```

그다음 `http://localhost:8765`로 접속해요. (`file://`로 직접 열면 스크립트 로딩 경로 때문에 동작이 달라질 수 있어요.)

## 구조

```
index.html     레이아웃 + 스타일
src/survey.js  설문 질문 데이터
src/cat.js     답변 → 고양이 속성, 타이틀/이름/이유 풀이, 손님 시드
src/render.js  속성 → 32x32 픽셀 그리드 → 캔버스 애니메이션
src/room.js    사랑방 (시즌 배경, 돌아다니는 고양이, 클릭 판정)
src/app.js     화면 흐름 (인트로 → 설문 → 별명 → 결과 → 사랑방)
docs/          README 예시 이미지
```

설계 배경은 [design.survey-to-cat.md](design.survey-to-cat.md), 서비스 기획은 [proj.cat-ddong.md](proj.cat-ddong.md)에 있어요.
